# 旅すご（v5）

道端の構造物になりきって写真を撮る、位置情報すごろくゲーム。

観光名所ではなく、マンホール・バス停・消火栓・彫刻といった「道端のどうでもいいもの」を旅の主役にする。オープンデータから盤面を自動生成し、サイコロを振って実際に歩き、着いた場所の被写体と同じポーズで写真を撮る。ルールはそれだけ。

**役に立つものは便利になって忘れられる。役に立たないものは思い出になる。**

大学の授業「デジタルメディア制作」の課題として制作（テーマ: 役に立たないものを作る）。

## 遊び方

1. プロフィールタブでニックネームを決める
2. 「マップ作成をはじめる」→ 地図で中心地点を選び、半径とマス数を決めて盤面を生成
3. 発行された6桁の部屋コードを仲間に共有
4. サイコロを振って、出た目のぶんルート上を進む
5. 目的地に着いたらGPSで到着判定 → 被写体と同じポーズで撮影 → 送信
6. 送信するとAIが自動採点（似ている度合いを星1〜5＋電柱の写り込みで判定）。他のメンバーの写真には絵文字リアクションを送れる（得点には無関係）
7. ゴールで「そっくり大賞」（👏最多）と「なにこれ大賞」（😆最多）を表彰

得点は **基礎点 × AIの星**。電柱が写り込んでいたら+5点（電柱もAIが判定）。人の相互採点は廃止し、判定はAIに全任せ。

## 技術構成

サーバに重い処理をさせない構成。**2つのバックエンド実装があり、どちらでも同一のフロントエンド・同一のAPI仕様で動く**。

- **Cloudflare版**（`functions/` + D1）… サーバ不要。`*.pages.dev` のURLでHTTPS付きで公開でき、そのままスマホで遊べる
- **自前Apache版**（`api/*.php` + SQLite）… 自分のサーバ／レンタルサーバにApache + PHPで設置する

```
ブラウザ（スマホ・PWA）
 ├── 地図表示 …… Leaflet + CARTO Voyager タイル
 ├── 盤面生成 …… JavaScript（目標マス間距離ベースの貪欲法）
 ├── GPS判定 …… Geolocation API（半径70m以内で到着）
 ├── 写真 …… 端末内で長辺1000px・JPEG品質0.75へ縮小してから送信
 └── オフライン …… Service Worker（アプリシェル・地図タイルをキャッシュ）

バックエンドA: Cloudflare Pages Functions + D1
 ├── functions/api/[[path]].js … 全APIを1ファイルで処理
 ├── 写真の保存と配信 …… D1にBLOBで保存（R2不使用）
 ├── AI採点（Workers AI ビジョン）と得点計算＋絵文字リアクション
 └── openrouteserviceへのプロキシ（キーは環境変数 ORS_API_KEY）

バックエンドB: Apache + PHP 8 + SQLite
 ├── api/index.php + api/lib.php … 同一仕様のPHP実装
 ├── 写真の保存と配信 …… api/data/ 配下にファイル保存
 ├── 相互採点と得点計算
 └── openrouteserviceへのプロキシ（キーは api/secrets.php）
```

両実装は「絶対に変えてはいけない仕様」（ネット投票の分離・本人のみ公開・取り下げで即削除・部屋メンバーのみ閲覧など）を満たす。`test_api.sh`（Apache版）と `test_api_cf.sh`（Cloudflare版）でそれぞれ検証できる。なお採点方式は分岐しており、**Cloudflare版はAI採点＋絵文字リアクション**、Apache版は従来の人による相互採点。仕様の正は `docs/仕様書.md`。

### 盤面生成のアルゴリズム

半径内の全候補から、**現在のマスから「目標マス間距離」に最も近い地点**を順に選ぶ。目標距離は `探索半径 × 0.24`（180〜900mでclamp）。

候補ごとにペナルティを加算し、最小の候補を採用する:

- 目標距離との差 `|距離 − 目標| ÷ 目標` を基本スコアとする
- 目標の55%未満に近すぎる候補に強いペナルティ（密集回避）
- 同じカテゴリの使用回数 × 0.58（消火栓だらけになるのを防ぐ）
- 直前と同カテゴリなら +0.35
- 選択済みマスに近づく場合はループ抑制ペナルティ
- 毎回同じ盤面にならないよう ±0.08 の揺らぎ

最短経路を作るのではなく「歩き応えのある間隔」を作るのが目的。

## セットアップ（Cloudflare版）

サーバを持たなくても、Cloudflareの無料枠だけで公開できる。必要なもの: Node.js 18以上とCloudflareアカウント（無料・クレジットカード不要）。

```bash
git clone https://github.com/<あなたのユーザー名>/monomane-sugoroku.git
cd monomane-sugoroku
npm install
```

### 1. ローカルで動かす

```bash
# D1データベースにスキーマを適用（ローカル）
npx wrangler d1 execute monomane-sugoroku --local --file=./migrations/0001_init.sql

# 徒歩経路APIキーを使う場合のみ（未設定でも動作。直線距離表示になる）
echo 'ORS_API_KEY=あなたのキー' > .dev.vars

# 起動
npx wrangler pages dev . --port 8788
```

ブラウザで <http://localhost:8788> を開く。APIの自動テストは別ターミナルで:

```bash
bash test_api_cf.sh
```

「絶対に変えてはいけない仕様」10項目（自己リアクション禁止・AI得点計算・ネット投票の分離・本人のみ公開・取り下げで即削除・部屋メンバーのみ閲覧など）を番号付きで検証する。

### 2. Cloudflareへデプロイ

```bash
npx wrangler login

# 本番D1を作成し、出力された database_id を wrangler.toml の
# [[d1_databases]] の database_id に貼る
npx wrangler d1 create monomane-sugoroku

# 本番D1にスキーマを適用
npx wrangler d1 execute monomane-sugoroku --remote --file=./migrations/0001_init.sql

# 徒歩経路APIキー（任意）を本番シークレットに登録
npx wrangler pages secret put ORS_API_KEY

# デプロイ
npx wrangler pages deploy .
```

発行された `https://*.pages.dev` のURLでスマホからそのまま遊べる（HTTPS付き）。GitHub連携（Pages の Git連携）を設定すれば、pushで自動デプロイもできる。

#### なぜ写真をD1にBLOB保存するのか（設計判断）

本来こうした画像はオブジェクトストレージ（Cloudflare R2）に置くのが定石だが、**R2は無料でも支払い方法（クレジットカード）の登録が必要**。授業課題として誰でもカード登録なしで再現できることを優先し、**写真はD1（SQLite）にBLOBとして保存**する方式を採った。

- D1無料枠: 1データベース最大 **500MB**・1行最大 **2MB**
- 写真はクライアント側で長辺1000px・JPEG品質0.75へ縮小（1枚 **約200KB**）
- 容量見積り: **500MB ÷ 200KB ≒ 2,500枚**。部屋は30日で自動削除されるため、授業規模なら十分

#### EXIF（GPS）除去についての方針変更

PHP版は `getimagesize()` でMIME検証し、GDで再エンコードしてEXIF（GPS含む）を除去していた。Workers環境には画像ライブラリが無いため、Cloudflare版では **①先頭バイト（マジックバイト）でのMIME検証** ＋ **②クライアント側でCanvasを通した再エンコード済みであること**で代替する。ブラウザのCanvasを経由した時点でEXIFは失われるため、GPS情報がサーバに残ることはない。

## セットアップ（自前Apache版）

必要なもの: PHP 8以上（`pdo_sqlite` と `gd` 拡張）

```bash
git clone https://github.com/<あなたのユーザー名>/monomane-sugoroku.git
cd monomane-sugoroku

# APIキーの設定（未設定でも動作する）
cp api/secrets.example.php api/secrets.php
# api/secrets.php を開き、openrouteserviceのキーを設定

# ローカルで起動
php -S localhost:8080 router.php
```

ブラウザで <http://localhost:8080> を開く。

### 本番（Apache）へ配置

```bash
sudo cp -r . /var/www/monomane-sugoroku/public/
sudo chown -R www-data:www-data /var/www/monomane-sugoroku/public/api/data
```

GPS・カメラ・PWAはHTTPSでのみ動作するため、Let's Encrypt等でのHTTPS化が必須。

### APIの動作確認

```bash
bash test_api.sh
```

部屋作成から相互採点、ネット公開・取り下げまでを自動検証する。

## プライバシーへの配慮

- 写真は**部屋のメンバーだけ**が閲覧できる（トークン認証）。作成から30日で自動削除
- 保存時にJPEGへ再エンコードし、**EXIFのGPS情報を除去**する
- 位置情報はサーバに送信しない（進行中のマス番号のみ同期）
- ネット公開は**本人の操作のみ**。公開前にモザイク・絵文字スタンプで顔を隠すエディタが必ず開く
- 公開はいつでも取り下げでき、取り下げると公開用画像と投票が即座に削除される
- ネット投票は部屋の得点に影響しない（ゲームの公平性を保つため）

## 安全に遊ぶために

- 車道・私有地・立入禁止区域には入らない
- 地面に寝るポーズは、安全な広場などで代替する
- 設備に触れたり、台座へ登ったりしない
- 通行人の顔や車両番号を無断で撮影しない
- 通行の妨げにならない場所で撮影する

アプリ起動時にこの内容への同意を求めている。
